# Printer configuration

This private repository tracks the Klipper/Moonraker configuration in `~/printer_data/config`.

`mainsail.cfg` and `timelapse.cfg` are host symlinks supplied by the separately managed `mainsail-config` and `moonraker-timelapse` repositories, so they are intentionally not tracked here. `.theme/`, logs, and the historical `.codex_backup/` are also excluded.

`sp_mmu.cfg` and `sp_mmu_code.cfg` are retained for reference but are not included by the active `printer.cfg`.
